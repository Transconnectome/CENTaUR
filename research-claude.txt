# CENTaUR 프로젝트 한국형 발달 임상 데이터 확장: 완전 구현 계획서

## 프로젝트 현황 분석

**중요 발견**: CENTaUR(2023)는 현재 **Llama-3.1-Centaur-70B**와 **Psych-201** 오픈 협업 프로젝트로 진화했습니다. 자연어로 표현된 대규모 심리학 실험 데이터(160개 실험, 60,092명 참가자, 1,068만 선택)로 Llama 3.1 70B를 미세조정하여 인간 인지의 통합 모델을 구축합니다. 저자들은 명시적으로 **다국어 및 발달 데이터 통합을 환영**하고 있어, 제안하신 확장이 프로젝트 전략과 완벽하게 일치합니다.

### 핵심 기술 구조

**데이터 형식**: JSONL 기반 자연어 전사본
- 인간 응답은 `<<` `>>` 토큰으로 표시
- 메타데이터: age, gender, education, language, country 지원
- 현재 한계: 영어 중심, WEIRD 인구 편향, 성인만 포함

**모델 아키텍처**: QLoRA (Quantized Low-Rank Adaptation)
- Llama 3.1 70B 기반
- Rank-8 어댑터 (전체 파라미터의 0.15%)
- 4비트 양자화, A100 80GB GPU 1개로 5일 학습
- 최대 시퀀스 길이: 32,768 토큰

## 핵심 기술적 도전과제 및 해결책

### 1. 한국어 토크나이징 효율성

**문제**: 한국어는 영어 대비 **2.36배 더 많은 토큰** 필요
**영향**: 32,768 토큰 제한으로 한국어 세션은 영어의 42%만 수용 가능

**해결책 3단계**:

```python
# 1단계: 한국어 어휘 확장
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-3.1-70B")
korean_vocab = ["나무", "자동차", "사과", ...]  # 5,000-10,000개
tokenizer.add_tokens(korean_vocab)
model.resize_token_embeddings(len(tokenizer))

# 2단계: 형태소 기반 전처리
from konlpy.tag import Mecab

mecab = Mecab()
def preprocess_korean(text):
    morphemes = mecab.morphs(text)
    return " ".join(morphemes)

# 3단계: 텍스트 압축
- 불필요한 공백 제거
- 메타데이터 필드 축약
- 반복 지시문 통합
```

### 2. 문화적 적응

**집단주의 vs 개인주의**: 한국 문화의 관계적 사고가 서구 과제의 탈맥락적 처리 가정과 충돌
**해결책**: 인지 인터뷰(N=30-40) + 파일럿 테스트(N=100+)로 문화적 동등성 검증

**과제별 적응 전략**:
- **높은 호환성**: 숫자 폭, 시각 패턴, 선로잇기 → 최소 수정
- **중간 호환성**: 기억 회상, 언어 유창성 → 한국어 규범 단어 목록 사용
- **낮은 호환성**: 속담 해석, 이야기 회상 → 한국 문화 콘텐츠로 완전 재구성

```python
from pydantic import BaseModel
from typing import Literal, Optional, Dict, List
from datetime import date

AgeGroup = Literal["infant", "preschool", "school-age", "adolescent", "adult"]
ParentalInvolvement = Literal[
    "present_observing",
    "present_verbal_prompting",
    "present_physical_assistance",
    "proxy_reporter",
    "absent"
]

class EnhancedParticipant(BaseModel):
    """확장된 참가자 메타데이터"""
    id: str
    age_months: Optional[int] = None  # 발달 데이터: 정밀도를 위한 월 단위
    age_years: Optional[int] = None   # 성인 데이터
    age_group: AgeGroup
    gender: Optional[str] = None
    education_years: Optional[int] = None
    language: str = "ko"  # 한국어 기본값
    country: str = "KR"
    region: Optional[str] = None  # 서울, 부산 등
    parental_involvement: Optional[ParentalInvolvement] = None
    
    developmental_profile: Optional[Dict] = {
        "language": {"receptive": "age_appropriate", "expressive": "age_appropriate"},
        "motor": {"gross": "age_appropriate", "fine": "age_appropriate"},
        "cognitive": {"attention_span_minutes": 30, "working_memory": "age_appropriate"},
        "social_emotional": {"peer_interaction": "age_appropriate"}
    }
    
    session_context: Optional[Dict] = {
        "guardian_present": False,
        "attention_breaks": 0,
        "session_duration_minutes": None
    }
    
    normative_context: Optional[Dict] = {
        "age_group": None,
        "education_group": None,
        "normative_mean": None,
        "normative_sd": None,
        "percentile_score": None
    }

class PsychExperiment(BaseModel):
    """Psych-201 실험 데이터"""
    text: str  # 자연어 전사본
    experiment: str  # 실험 ID
    participant: EnhancedParticipant
    questionnaire_metadata: Optional[Dict] = None
    RTs: Optional[List[float]] = None
    
    def to_jsonl_line(self) -> str:
        return json.dumps(self.dict(exclude_none=True), ensure_ascii=False)
```

```python
import json
import random
from pathlib import Path

class KMMSEPromptGenerator:
    """한국판 간이정신상태검사 생성기"""
    
    def __init__(self):
        # 한국어 고빈도 명사 목록
        self.word_lists = [
            ["나무", "자동차", "모자"],
            ["비행기", "연필", "소나무"],
            ["꽃", "강아지", "시계"]
        ]
        self.button_keys = ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
    
    def generate_session(self, participant_id: str, age: int, 
                        education: int, gender: str, 
                        responses: Dict) -> Dict:
        """한 참가자의 전체 K-MMSE 세션 생성"""
        
        words = random.choice(self.word_lists)
        orientation_keys = random.sample(self.button_keys, 5)
        
        session_text = f"""이제 몇 가지 질문을 드리겠습니다. 각 질문에 대해 해당하는 버튼을 눌러주세요.

지남력 평가:
오늘은 몇 년도인가요? <<{orientation_keys[0]}>> {responses['year']}년입니다.
오늘은 몇 월인가요? <<{orientation_keys[1]}>> {responses['month']}월입니다.
오늘은 무슨 요일인가요? <<{orientation_keys[2]}>> {responses['day']}입니다.
지금 어디에 계신가요? <<{orientation_keys[3]}>> {responses['location']}입니다.
여기는 몇 층인가요? <<{orientation_keys[4]}>> {responses['floor']}층입니다.

기억 등록:
제가 말하는 세 단어를 잘 들으시고 따라 말씀해주세요: {words[0]}, {words[1]}, {words[2]}.
<<{words[0]}, {words[1]}, {words[2]}>>

주의집중 및 계산:
100에서 7씩 빼세요.
<<93>> <<86>> <<79>> <<72>> <<65>>

기억 회상:
처음에 제가 말씀드린 세 단어가 무엇이었는지 말씀해주세요.
<<{', '.join(responses['recall'])}>>

언어 기능:
(연필을 보여주며) 이것이 무엇입니까? <<연필>>
(시계를 보여주며) 이것이 무엇입니까? <<시계>>

다음 문장을 따라 말씀해주세요: "간장 공장 공장장"
<<간장 공장 공장장>>

제가 하는 말을 따라 하세요: 오른손으로 종이를 받아서, 반으로 접은 다음, 무릎 위에 놓으세요.
<<오른손으로 받는다>> <<반으로 접는다>> <<무릎에 놓는다>>

(종이에 "눈을 감으세요"라고 쓰여있음) 이것을 읽고 그대로 해주세요.
<<눈을 감는다>>

아무 문장이나 하나 써주세요.
<<{responses['sentence']}>>

이 그림을 따라 그려주세요.
<<그림 완성>>
"""
        
        return {
            "text": session_text.strip(),
            "experiment": "k_mmse",
            "participant": {
                "id": participant_id,
                "age_years": age,
                "age_group": "adult",
                "gender": gender,
                "education_years": education,
                "language": "ko",
                "country": "KR",
                "normative_context": {
                    "age_group": self._get_age_group(age),
                    "education_group": self._get_education_group(education),
                    "total_score": responses.get('total_score', None)
                }
            }
        }
    
    def _get_age_group(self, age: int) -> str:
        if age < 60: return "middle_age"
        elif age < 75: return "young_old"
        else: return "old_old"
    
    def _get_education_group(self, education: int) -> str:
```

```python
class PHQ9AdolescentGenerator:
    """청소년 우울증 선별 설문 생성기"""
    
    QUESTIONS_KO = [
        "지난 2주 동안, 얼마나 자주 일을 하는 데 흥미나 즐거움이 거의 없었습니까?",
        "지난 2주 동안, 얼마나 자주 기분이 가라앉거나, 우울하거나, 희망이 없다고 느꼈습니까?",
        "지난 2주 동안, 얼마나 자주 잠들기 어렵거나, 자주 깨거나, 너무 많이 잠을 잤습니까?",
        "지난 2주 동안, 얼마나 자주 피곤함을 느끼거나 기운이 거의 없었습니까?",
        "지난 2주 동안, 얼마나 자주 식욕이 줄었거나 과식을 했습니까?",
        "지난 2주 동안, 얼마나 자주 자신이 실패자라고 느끼거나, 자신 또는 가족을 실망시켰다고 느꼈습니까?",
        "지난 2주 동안, 얼마나 자주 신문을 읽거나 TV를 보는 것과 같은 일에 집중하기 어려웠습니까?",
        "지난 2주 동안, 얼마나 자주 다른 사람들이 알아챌 정도로 움직이거나 말하기가 느렸습니까?",
        "지난 2주 동안, 얼마나 자주 자신을 해치거나 차라리 죽는 것이 낫겠다는 생각을 했습니까?"
    ]
    
    RESPONSE_OPTIONS = ["전혀 없음", "며칠 동안", "7일 이상", "거의 매일"]
    
    def generate_questionnaire(self, participant_id: str, age_months: int, 
                               responses: List[int]) -> Dict:
        """PHQ-9 설문 생성"""
        
        preamble = """이 설문지는 지난 2주 동안 당신의 기분에 대해 묻습니다. 
정직하게 답변해 주세요. 정답이나 오답은 없습니다.

각 질문에 대해: 전혀 없음, 며칠 동안, 7일 이상, 거의 매일 중 선택하세요.

"""
        
        questions_text = []
        for i, (question, response_idx) in enumerate(zip(self.QUESTIONS_KO, responses), 1):
            response = self.RESPONSE_OPTIONS[response_idx]
            questions_text.append(f"질문 {i}: {question}\n<<{response}>>\n")
        
        full_text = preamble + "\n".join(questions_text)
        total_score = sum(responses)
        
        return {
            "text": full_text,
            "experiment": "adolescent_depression_phq9",
            "participant": {
                "id": participant_id,
                "age_months": age_months,
                "age_years": age_months // 12,
                "age_group": "adolescent",
                "parental_involvement": "absent",
                "language": "ko",
                "country": "KR"
            },
            "questionnaire_metadata": {
                "instrument": "PHQ-9",
                "version": "adolescent_korean",
                "total_items": 9,
                "scoring": {
                    "total_score": total_score,
                    "severity": self._get_severity(total_score),
                    "clinical_cutoff": 10,
                    "range": "0-27"
                }
            }
        }
    
    def _get_severity(self, score: int) -> str:
        if score < 5: return "minimal"
        elif score < 10: return "mild"
        elif score < 15: return "moderate"
        elif score < 20: return "moderately_severe"
        else: return "severe"
```

### Phase 4: 한국 규준 데이터 통합

```python
class KoreanNormativeCalculator:
    """한국 인구 기반 규준 계산기"""
    
    def __init__(self, norms_database_path: str):
        """규준 데이터베이스 로드"""
        with open(norms_database_path, 'r') as f:
            self.norms = json.load(f)
    
    def get_adjusted_score(self, test_name: str, raw_score: float,
                           age: int, education_years: int, 
                           gender: str) -> Dict:
        """인구통계학적으로 조정된 점수 계산"""
        
        test_norms = self.norms[test_name]
        
        # 회귀 기반 규준
        predicted_score = (
            test_norms['intercept'] +
            test_norms['age_coef'] * age +
            test_norms['education_coef'] * education_years +
            test_norms['gender_coef'][gender]
        )
        
        # Z-점수 및 백분위 계산
        z_score = (raw_score - predicted_score) / test_norms['residual_sd']
        from scipy.stats import norm
        percentile = norm.cdf(z_score) * 100
        
        return {
            'raw_score': raw_score,
            'predicted_score': predicted_score,
            'z_score': z_score,
            'percentile': percentile,
            'age_group': self._classify_age(age),
            'education_group': self._classify_education(education_years)
        }
    
    def _classify_age(self, age: int) -> str:
        if age < 40: return "young_adult"
        elif age < 60: return "middle_age"
        elif age < 75: return "young_old"
        elif age < 85: return "old_old"
        else: return "oldest_old"
    
    def _classify_education(self, years: int) -> str:
        if years < 7: return "elementary"
        elif years < 10: return "middle_school"
        elif years < 13: return "high_school"
        else: return "university_plus"
```

### Phase 5: 모델 학습 파이프라인

```python
from unsloth import FastLanguageModel
from datasets import load_dataset
from trl import SFTTrainer
from transformers import TrainingArguments

def train_korean_developmental_centaur(
    train_jsonl_path: str,
    output_dir: str = "./centaur-korean-dev",
    base_model: str = "unsloth/Meta-Llama-3.1-70B-bnb-4bit"
):
    """한국어 + 발달 데이터로 Centaur 확장 학습"""
    
    # 1. 모델 및 토크나이저 로드
    model, tokenizer = FastLanguageModel.from_pretrained(
        model_name=base_model,
        max_seq_length=32768,
        dtype=None,
        load_in_4bit=True,
    )
    
    # 2. LoRA 어댑터 설정
    model = FastLanguageModel.get_peft_model(
        model,
        r=8,  # Rank
        target_modules=[
            "q_proj", "k_proj", "v_proj", "o_proj",
            "gate_proj", "up_proj", "down_proj"
        ],
        lora_alpha=16,
        lora_dropout=0,
        bias="none",
        use_gradient_checkpointing="unsloth",
        random_state=3407,
    )
    
    # 3. 데이터셋 로드
    dataset = load_dataset('json', data_files={'train': train_jsonl_path})
    
    # 4. 응답 마스킹 적용
    def format_prompts(examples):
        """<< >> 내부만 학습하도록 마스킹"""
        texts = []
        for text in examples['text']:
            # Centaur 포맷: << >> 내부가 학습 타겟
            texts.append(text)
        return {'formatted_text': texts}
    
    dataset = dataset.map(format_prompts, batched=True)
    
    # 5. 학습 설정
    trainer = SFTTrainer(
        model=model,
        tokenizer=tokenizer,
        train_dataset=dataset['train'],
        dataset_text_field="formatted_text",
        max_seq_length=32768,
        args=TrainingArguments(
            per_device_train_batch_size=1,
            gradient_accumulation_steps=32,  # 효과적 배치 크기 = 32
            warmup_steps=100,
            learning_rate=5e-5,
            num_train_epochs=1,
            weight_decay=0.01,
            logging_steps=10,
            output_dir=output_dir,
            optim="adamw_8bit",
            fp16=not torch.cuda.is_bf16_supported(),
            bf16=torch.cuda.is_bf16_supported(),
            save_strategy="steps",
            save_steps=1000,
        ),
    )
    
    # 6. 학습 실행
    trainer.train()
    
    # 7. 어댑터 저장
    model.save_pretrained(f"{output_dir}/final_adapter")
    tokenizer.save_pretrained(f"{output_dir}/final_adapter")
    
    print(f"Training complete! Adapter saved to {output_dir}/final_adapter")

# 실행 예시
if __name__ == "__main__":
    train_korean_developmental_centaur(
        train_jsonl_path="data/combined_korean_dev_train.jsonl",
        output_dir="./centaur-ko-dev-v1"
    )
```

### Phase 6: 평가 및 검증

```python
import numpy as np
from sklearn.metrics import accuracy_score, f1_score
from scipy.stats import pearsonr
import re

class CentaurEvaluator:
    """Centaur 모델 평가 시스템"""
    
    def __init__(self, model, tokenizer):
        self.model = model
        self.tokenizer = tokenizer
    
    def evaluate_choice_accuracy(self, test_data: List[Dict]) -> Dict:
        """선택 정확도 평가"""
        
        correct = 0
        total = 0
        predictions = []
        ground_truth = []
        
        for item in test_data:
            # 프롬프트 추출 (응답 제거)
            prompt = self._remove_responses(item['text'])
            
            # 모델 예측
            predicted = self._generate_response(prompt)
            
            # 실제 응답 추출
            actual = self._extract_first_response(item['text'])
            
            predictions.append(predicted)
            ground_truth.append(actual)
            
            if predicted == actual:
                correct += 1
            total += 1
        
        return {
            'accuracy': correct / total if total > 0 else 0,
            'total_samples': total,
            'predictions': predictions,
            'ground_truth': ground_truth
        }
    
    def evaluate_by_age_group(self, test_data_dict: Dict[str, List[Dict]]) -> Dict:
        """연령대별 성능 평가"""
        
        results = {}
        for age_group, data in test_data_dict.items():
            results[age_group] = self.evaluate_choice_accuracy(data)
        
        return results
    
    def evaluate_korean_vs_english(self, korean_data: List[Dict], 
                                   english_data: List[Dict]) -> Dict:
        """한국어 vs 영어 성능 비교"""
        
        ko_results = self.evaluate_choice_accuracy(korean_data)
        en_results = self.evaluate_choice_accuracy(english_data)
        
        return {
            'korean_accuracy': ko_results['accuracy'],
            'english_accuracy': en_results['accuracy'],
            'gap': ko_results['accuracy'] - en_results['accuracy'],
            'korean_n': ko_results['total_samples'],
            'english_n': en_results['total_samples']
        }
    
    def _generate_response(self, prompt: str) -> str:
        """모델로 응답 생성"""
        FastLanguageModel.for_inference(self.model)
        
        inputs = self.tokenizer(prompt, return_tensors="pt").to("cuda")
        outputs = self.model.generate(
            **inputs,
            max_new_tokens=100,
            temperature=0.7,
            do_sample=True
        )
        
        response = self.tokenizer.decode(outputs[0], skip_special_tokens=True)
        
        # << >> 내부 추출
        match = re.search(r'<<(.+?)>>', response)
        if match:
            return match.group(1).strip()
        return ""
    
    def _remove_responses(self, text: str) -> str:
        """응답 제거"""
        return re.sub(r'<<.+?>>', '<<', text)
    
    def _extract_first_response(self, text: str) -> str:
        """첫 번째 응답 추출"""
        match = re.search(r'<<(.+?)>>', text)
        return match.group(1).strip() if match else ""

# 평가 실행
evaluator = CentaurEvaluator(model, tokenizer)

# 연령대별 평가
age_group_results = evaluator.evaluate_by_age_group({
    "infant": infant_test_data,
    "preschool": preschool_test_data,
    "school-age": school_age_test_data,
    "adolescent": adolescent_test_data,
    "adult": adult_test_data
})

print("연령대별 정확도:")
for age_group, results in age_group_results.items():
    print(f"{age_group}: {results['accuracy']:.2%} (N={results['total_samples']})")

# 언어 간 비교
language_results = evaluator.evaluate_korean_vs_english(
    korean_test_data, 
    english_test_data
)

print(f"\n언어 간 성능:")
print(f"한국어: {language_results['korean_accuracy']:.2%}")
print(f"영어: {language_results['english_accuracy']:.2%}")
print(f"차이: {language_results['gap']:.2%}")
```

- 기본 평가 도구

**결과물**:

- 성능 파일럿 데이터

### MVP 실행 계획

**Week 1-2: 설정**
```bash
# 저장소 생성
git clone https://github.com/marcelbinz/Psych-201.git
cd Psych-201
mkdir korean_developmental_extension
cd korean_developmental_extension

# 환경 설정
conda create -n centaur-ko python=3.10
conda activate centaur-ko
pip install -r requirements.txt

# 디렉토리 구조
mkdir -p {korean_tasks/k_mmse,developmental_tasks/adolescent_phq9,shared,tests}
```

**Week 3-6: 데이터 생성**
```python
# k_mmse/generate_prompts.py 작성 (앞의 코드 사용)
# adolescent_phq9/generate_prompts.py 작성

# 파일럿 데이터 생성
python korean_tasks/k_mmse/generate_prompts.py \
    --input raw_data/k_mmse_pilot.csv \
    --output korean_tasks/k_mmse/prompts.jsonl

python developmental_tasks/adolescent_phq9/generate_prompts.py \
    --input raw_data/phq9_pilot.csv \
    --output developmental_tasks/adolescent_phq9/prompts.jsonl
```

**Week 7-10: 학습**
```python
# 데이터 통합
cat korean_tasks/*/prompts.jsonl \
    developmental_tasks/*/prompts.jsonl \
    > combined_pilot.jsonl

# 학습 실행
python train_korean_developmental.py \
    --train_data combined_pilot.jsonl \
    --output_dir ./centaur-ko-dev-mvp \
    --epochs 1
```

**Week 11-12: 평가 및 발표**
```python
# 평가
python evaluate.py \
    --model_path ./centaur-ko-dev-mvp \
    --test_data test_pilot.jsonl

```
